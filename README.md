# BROZZU — Signature Collection (annonces en ligne)

Mini-sites immersifs des biens de BROZZU – L'Atelier Immo, servis par GitHub Pages
sur https://annonces.brozzu.fr.

Un dossier par bien (ex. `appartement-vue-port-port-de-bouc/`), généré depuis le projet
`signature/` du dépôt brozzu-estimation. Les fiches acquéreurs sont relayées par e-mail via
FormSubmit ; la prise de rendez-vous se fait dans l'agenda Google du conseiller.
